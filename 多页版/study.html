第一次跑通 Hello World

学了什么

遇到什么问题

2026-11-08 · C 语言

实验 5-2：成绩管理程序

学了什么
二维数组存学号和成绩，选择排序整理顺序，二分查找按学号查询。
遇到什么问题
getchar 读字符受编码影响；char name[100] 装不下多个名字；二分写成 low ≥ high，最后一个元素永远查不到。
怎么处理
字符只用于菜单，名字改用二维数组加 strcpy，二分改成 low ≤ high，找不到返回 -1。

2026-11 · GPU

OpenCL 带宽测出 92487 GB/s

学了什么
C 调 OpenCL，写 kernel 做内存读写，用 event 计时，按字节数除耗时算带宽。
遇到什么问题
把 CUDA 的 grid 当成 OpenCL 的 global work size，少算了每组工作项，数字比物理带宽大两个数量级。
怎么处理
改成 global = group 数 × 每组工作项数，并按总工作项算字节数，回到 515 GB/s 附近。计时是否含启动开销还没确认。
