GPU 性能测试工具

问题：测显存读写带宽，判断不同 work size 下结果是否可信。
我负责：实验设计、kernel 编写、计时和结果核对。
技术：C + OpenCL。
困难：把 CUDA 的 grid 当成 global work size，测出 92487 GB/s；按总工作项重算后回到 515 GB/s，计时方式还在验证。

成绩管理程序

问题：管理学号和成绩，支持录入、排序和按学号查询。
我负责：全部代码和测试。
技术：C89、二维数组、选择排序、二分查找。
困难：二分边界写成 low ≥ high 漏掉最后一个元素，改成 low ≤ high 才对。

实验报告自动化

问题：实验报告格式固定，手动排版慢还容易漏。
我负责：脚本设计、模板格式对照、代码一致性校验。
技术：Python + python-docx，导出 PDF。
困难：GBK 编码、WPS 占用文件、目录页码要从 PDF 回填。

“我和新时代的故事”演讲 PPT

问题：18 页、10 分钟演讲的版式和动效。
我负责：讲稿、结构、python-pptx 脚本。
技术：Python + OOXML。
困难：渐变单位、transition 顺序、Morph 同名，改完还要按 F5 手测。

校园失物招领需求分析

问题：定义发布、搜索、认领、审核的需求。
我负责：角色、功能、验收标准。
技术：需求文档。
困难：“能搜索”不是验收标准，要写清输入、响应时间和筛选维度。

Python 自动化
python-docx 生成实验报告，python-pptx 做 18 页演讲 PPT。证据：实验 4、5-2 的报告和演讲 PPT。
def replace_in_paragraph(p, old, new):
    for run in p.runs:
        if old in run.text:
            run.text = run.text.replace(old, new)
