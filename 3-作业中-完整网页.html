  1. 2026-11-16 英语
    进行中

    阅读难度跳档之后，错题暴露了真正的问题

    学了什么
    每天三篇英文阅读加选择题。前几天的文章连着两次 9/9，就把材料换成了更抽象的观点文，限时 8 分钟一篇。

    怎么处理
    从 Day 05 开始加“句意改写题”和难句拆解，并定了个规矩：一次只升一个维度，长度、句式、题型不能同时加。现在还在按这个节奏练，跨篇题的正确率还没稳定到 80%。
  2. 2026-11-09 ~ 11-10 英语
    已解决

    连续两次 9/9，才开始加难度

    学了什么
    按“记忆、睡眠、注意力”和“考试焦虑、刻意练习、协作学习”分主题读三篇一组，每组 9 道选择题，生词只留 4 个重点词。

    第一组有一道题错在把“疲惫让一切看起来更糟”引申成“喘不过气”，还有一道漏掉了 not A, but B 里的否定项。
    怎么处理
    每篇做完先在原文里标出错题定位段，再写一句“我为什么被这个选项骗到”。第二组开始连续两次 9/9，才决定把难度往上加。
  3. 2026-11 GPU
    待验证

    OpenCL 带宽测出来 92487 GB/s，明显不对劲

    学了什么
    用 C 调 OpenCL：写 kernel 做内存读写、设置 global / local work size、用 event 计时，再按“传输字节数 ÷ 耗时”算带宽。
    卡在哪里
    第一次测出的数字比显卡物理带宽大两个数量级。回头检查才发现，我把 CUDA 的 grid 当成 OpenCL 的 global work size，少算了每组里的工作项。
    怎么处理
    改成 global = group 数 × 每组工作项数，并按总工作项数算字节数，结果回到 515 GB/s 附近。还没完全确认计时是否包含 kernel 启动开销，也没做多轮取平均，准备再测一轮。
  4. 2026-11 课程
    已解决

    写《长安三万里》影评：换个角度，论点才立得住

    卡在哪里
    按“流水账”“李白塌房”的思路写，论点容易变成剧情复述，也解释不了电影为什么让高适来讲这个故事。
    怎么处理
    把问题换成“谁在讲、讲给谁”：高适被问话，李白是他讲述的对象，所以观众看到的是“高适版的李白”。不可靠叙述不是毛病，而是影片的方法。改完角度后，论文才顺下来。
  5. 2026-11 课程
    进行中

    校园失物招领：把“能搜索”拆成验收标准

  6. 2026-11-08 C 语言
    已解决

    实验 5-2：用二维数组写成绩管理

    学了什么
    用二维数组存学号和成绩，选择排序整理顺序，二分查找按学号定位；字符串用 strcpy 拷贝，输入用 scanf，最后把查询结果打印出来。
    卡在哪里
    三个问题：getchar 读字符时碰到中文编码，读到的是字节，菜单会乱跳；char name[100] 只放得下一个名字，存多个就溢出；二分查找写成 low >= high，最后一个元素永远比不到。
    怎么处理
    字符只用于菜单选项，名字改用二维数组加 strcpy；二分条件改成 low <= high，找不到返回 -1。最后拿第一个、最后一个、不存在的学号各测了一遍。
  7. 2026-11-07 C 语言
    已解决

    实验 4：把程序拆成多个文件

    学了什么
    预处理阶段的几件事：宏定义和带参宏、条件编译、多文件工程（.h 放声明、.c 放实现）、用 assert 守住开发阶段的假设。
    卡在哪里
    习惯性多写了一个 #include <string.h>，其实没用到，编译一直提示；另外在 VC++ 2010 里把变量声明写在语句后面，直接编译报错。
    怎么处理
    只保留真正用到的头文件；把变量声明统一挪到代码块开头，按 C89 的规矩写，就过了。也记住了 C99 才支持随时声明变量。
  8. 2026-10 Python
    已解决

    用 python-pptx 做“我和新时代的故事”演讲 PPT

    学了什么
    用 python-pptx 生成 18 页、10 分钟的演讲 PPT，试着把渐变蒙版、转场和“平滑”效果写进 OOXML。
    卡在哪里
    被评审打回三次。给照片加渐变蒙版后整页均匀变灰，原因是色标位置单位是千分之一百分比，写成了 ×1000；视频页后面的转场总是丢，因为 <p:transition> 被排到了 <p:timing> 后面；Morph 只认同名元素。
    怎么处理
    改单位、把 transition 插到 timing 之前、统一形状 name。转场和视频播放没法用 LibreOffice 验证，只能每次按 F5 手动看。
  9. 2026-10 Python
    已解决

    用 python-docx 自动生成实验报告

    学了什么
    按模板生成实验报告 docx：控制字体、行距、缩进和页边距，把代码从源文件读进来，再导出 PDF；另外写了脚本检查代码和报告是否逐行一致。
    卡在哪里
    作业目录里的 .c 文件是 GBK 编码，按 UTF-8 读会乱码；WPS 开着文档时保存直接 PermissionError；目录页码得从导出的 PDF 反查后再回填。
    怎么处理
    读写都按 GBK + CRLF；保存前先探测文件有没有被占用；目录页码用脚本从 PDF 里找标题位置回填。现在实验 4 和 5-2 的报告都能一次生成。
  10. 2026-10 C 语言
    已解决

    第一次跑通 Hello World

    学了什么

03

实验报告自动排版脚本

已完成
Python python-docx 文档自动化
解决什么问题
实验报告有固定的字体、行距、缩进、图表题注和目录格式，每次手动排版既慢又容易漏。用脚本按模板生成 docx，再统一导出 PDF。
我负责什么
